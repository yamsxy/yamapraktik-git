# Project Konversi Suhu

## Deskripsi
Program sederhana menggunakan bahasa Go
untuk melakukan konversi suhu dari Celsius
ke Fahrenheit dan Kelvin.

## Fitur Program
- Konversi Celsius ke Fahrenheit.
- Konversi Celsius ke Kelvin.
- Validasi input agar hanya menerima angka.

## Teknologi yang Digunakan
- Bahasa pemrograman Go
- Git
- GitHub
- Visual Studio Code

## Cara Menjalankan Program
1. Pastikan Go sudah terinstal.
2. Buka terminal pada folder project.
3. Jalankan perintah:

go run main.go
